# Develop review — 29 September 2026

Tracking: `lap-eff`. Branch: `pebbles-harness/raw-development`.

## Scope and root cause

Reviewed the actual Develop UI → frontend session → Tauri IPC → shared model → engine session → sidecar/catalog path, including asynchronous save/navigation behavior, import retention, preview transport, control reset and database startup. This is a focused deep review of the extracted RAW integration, not a security audit of every Lap subsystem.

The screenshot is a real contract failure. An unopened/uncommitted sidecar is revision **0** in Lap, but the shared model requires revision **1 or greater**. `develop_parse_envelope` validated before the session layer could translate revisions. Thus a fresh photo could neither render a Develop preview nor save its first edit. Previous service tests bypassed the IPC parser; frontend tests mocked successful commits.

## Concrete corrections implemented

| Severity | Finding | Correction and regression |
| --- | --- | --- |
| P1 | Fresh revision-zero envelopes rejected before both preview and first save. | New `develop/wire.rs` translates sidecar revision to engine revision with checked addition before strict shared validation. Reject missing/negative/string/overflow revisions and invalid recipes. Session test now sends the actual opened JSON through this adapter into preview and commit. Durable sidecar validation stays strict. |
| P1 | Edits made during an in-flight commit were marked saved although only an older snapshot reached disk. | Drain changed snapshots in order; only mark the current recipe clean when its own snapshot has been acknowledged. Test changes exposure during a deferred write and verifies the second revision. |
| P1 | Failed import metadata leaked to another asset and disappeared on later retry. | Retain envelope patches per asset, clear when switching/closing, restore on reopen and send on off-screen retry. Test failed import, edit another image, return and retry. |
| P1 | Failed reopen consumed the only retained recipe before decoding succeeded. | Peek retained state and remove it only after a successful open. Regression injects decode failure. |
| P1 | A delayed pixel transfer could replace a newer generation after the ticket was checked. | Recheck lifetime/session/generation after the raw-byte await. Deferred transfer regression verifies the newest frame survives. |
| P1 | Late commit completion could resurrect a closed or replaced frontend session. | Apply acknowledgments only to the still-active matching session. Deferred commit/close regression. |
| P1 | Rapid opens/closes could interleave different assets and pending writes. | Serialize editor navigation and close; cancel superseded low-level opens and clean their backend sessions; close completion cannot clear a newer session. Rapid navigation regression. |
| P1 | Existing version-19 catalog skipped branch migration 18, leaving `adevelop_recipes` absent (also observed in real startup log). | Ensure the additive, idempotent projection schema regardless of version, without lowering `user_version` or changing source records. Test starts with version 19 and a preserved file row, migrates twice. |
| P2 | Reset of a nested color parameter wrote a literal dotted key instead of changing the nested value. | Use the same path-aware setter as normal editing; preserve undo history. Regression resets `colorCalibration.redHue`. |
| P2 | Preview failures were absent from the control panel while stale responses could clear the latest error/loading state. | Visible alert beside controls; request-scoped error and loading updates. Component and deferred-response regressions. |
